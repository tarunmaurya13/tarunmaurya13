### 🚀 Featured Projects

#### 🛡️ [Fraud Detection API + AI Analyst Copilot](https://github.com/tarunmaurya13/fraud-detection-copilot)
End-to-end fraud detection system on the NeurIPS 2022 Bank Account Fraud dataset (1M rows, 1.1% fraud rate), extended with an LLM-powered copilot layer.
- Temporal train/test split to reflect real deployment conditions, not random splitting
- XGBoost model tuned via RandomizedSearchCV, evaluated on PR-AUC (not accuracy) given severe class imbalance
- SHAP-based explainability feeding into an LLM that generates plain-English case notes for fraud analysts, with a grounded follow-up chat interface
- Graceful degradation: falls back to templated explanations if the LLM provider is unavailable
- Deployed as a live FastAPI service on Render

**Stack:** XGBoost · SHAP · FastAPI · Gemini API · Render
